TwitchCraft Store — Privacy Notice

Last updated: 2026-10-06

This Twitch Extension (“TwitchCraft Store”) lets viewers click in-game Minecraft commands on a broadcaster’s stream. It is operated by the channel / developer that installs it (not by Twitch).

What we collect

  • When you grant Identity Link, we receive your Twitch user id from Twitch and may look up your Twitch login (username) so the Minecraft announce can show your name.
  • If you do not link identity, we only receive an opaque Twitch viewer id (or a placeholder such as “viewer”).
  • We receive the command you click (for example #cow) and the channel context needed to run it on that stream’s game.

How we use it

Data is used only to authorize the click, run the matching Minecraft command on the broadcaster’s local game server, and show the normal in-game announce. We do not sell personal data, run third-party ads, or use analytics SDKs in this Extension.

Where it is processed

Clicks are sent to the broadcaster’s Extension Backend Service (EBS), which verifies the Twitch Extension JWT and forwards the command to Minecraft on that same machine. Processing happens on the broadcaster’s equipment for the duration of the stream / session.

Retention

We do not operate a long-term viewer database for this Extension. Transient request logs may exist only on the broadcaster’s machine while testing or streaming and are not used for marketing.

Sharing

We do not share viewer identity with third parties for this feature, other than what Twitch already provides to the Extension and what appears in the public Minecraft chat announce on that stream.

Your choices

You can decline Identity Link and still use the store with an opaque id. You can stop using the Extension at any time. Broadcasters can disable the Extension on their channel.

Contact

Questions about this notice: contact the channel that runs TwitchCraft (Twitch: raysunshine_rr) or the Extension developer listed in the Twitch Developer Console.
